Bank.Domain - Pruebas unitarias con NUnit

La solución Bank contiene Bank.Domain y Bank.Domain.Tests sobre .NET 10.

BankAccount conserva el titular y el saldo; Debit resta un importe permitido y Credit lo suma. Se conserva el tipo double de la guía, usando tolerancia 0.001 en las comprobaciones. Los retiros superiores al saldo y los importes negativos se rechazan mediante ArgumentOutOfRangeException.

Los 10 casos NUnit comprueban construcción, débito válido, débito cero y total, ambos errores de débito, crédito positivo, crédito cero, crédito desde saldo cero y crédito negativo. Las excepciones se exigen con Assert.Throws, de modo que la prueba también falla si no se lanza el error esperado.

La etapa RED reproduce el débito incorrecto con += y verifica un fallo real; GREEN usa -= y comprueba que el mismo caso pasa. Los resultados TRX se conservan como artefactos de GitHub Actions.

La referencia API se genera a partir de comentarios XML. El reporte HTML de cobertura está disponible en la sección coverage del sitio principal.
